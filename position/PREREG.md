# PREREG · 仓位管理（2026-11-03，跑数之前写）

**目的**：信号层（S2：20/60/120 日动量 + 60 日线 + 逆波动，k=5，5 日调仓）已经过 P1/P2 预登记检验；
本实验只检验"仓位层"——总敞口怎么定、单票怎么限、回撤怎么处理。

**数据**：`data/cache2019`，ext（52 只 ETF，2019-08-13 起可投）与 base（30 只）两池；
2026-11-02 快照；单边成本 5bp；收盘信号、次日收盘成交（delay=1）。
**性质**：同一批数据上的再检验，**不是样本外**。结论按"跨池 + 跨子段 + 对照固定同仓位"三关判。

## 假设与判据

### H1 波动率目标（vol targeting）
`敞口 = clip(目标波动 / 策略 60 日已实现波动, 0, 1)`，每日更新。
- 判据（ext 与 base 都要满足）：
  1. 与**同平均仓位的固定仓位**相比，卡玛提高 ≥ 0.05；
  2. 最大回撤比基线改善 ≥ 5pp；
  3. 夏普不低于同仓位固定对照 0.02 以上（bootstrap 90% 区间下沿 > -0.05）；
  4. 训练/验证/测试三段中 ≥ 2 段卡玛优于同仓位对照。
- 若只满足"回撤降但卡玛不升"，降级为"降风险工具"，不算风险调整后改善。

### H2 回撤节流（drawdown throttle）
净值回撤 -10% 降到 70% 仓、-15% 降到 40%、-20% 空仓；回撤修复到 -5% 内恢复满仓。
- 判据：最大回撤比基线改善 ≥ 3pp；卡玛 ≥ 基线；成本拖累 ≤ +0.30pp/年。

### H3 个券上限
逆波动权重后单票上限 30%（超出部分按比例分给其余，全部触顶则留现金）。
- 判据：卡玛相对基线下降 ≤ 0.03；回撤不变差；组合内最大单票权重 ≤ 30%（构造保证）。

### H4 止损
- 12% 固定止损（自首次建仓价）与"跌破 60 日线止损"两种。
- 判据：卡玛 ≥ 基线 + 0.03 **或** 回撤改善 ≥ 5pp；且年化不低于基线 2pp。达不到即判"有害/无用"，不纳入策略。

### H5 组合规则
H1 的 12% 目标 + H2 + H3 上限 30%。
- 判据：卡玛 ≥ max(单规则) - 0.02；平均仓位 ≥ 60%；成本拖累 ≤ 1.0pp/年；三段中 ≥ 2 段不差于基线。

### H6 更新频率（执行成本）
H1 每日更新 vs 每 5 日 / 每 20 日更新。
- 判据：低频版本保留 ≥ 80% 的卡玛改善，双边换手至少低 20%。

## 多重检验与解读
- 共 24 个变体 × 2 池；不逐条做 Bonferroni（探索性筛选），但**只有跨池、跨段、对同仓位对照都成立**才写进结论。
- 已知 2019-2026 是动量大年；vol targeting 在既有 wiki 研究（17 指数、2009-2026）也压回撤，属于**同方向外部证据**，不是独立样本。
- 成本只建模单边费率，未建模冲击/流动性；换手高的变体要打折看。

## 预期（写下来便于事后打脸）
- H1 大概率通过（既有 P1 的 S3 与 wiki 研究都指向"降回撤、卡玛升"），但 12% 目标在 ETF 池可能把平均仓位压到 50% 以下，年化让渡大。
- H2 单独用大概率"降回撤但不升卡玛"；与 H1 叠加可能只增加换手。
- H3 影响很小（k=5 时逆波动权重通常 15%~30%）。
- H4 止损大概率有害（wiki 研究：固定止损在 A 股板块普遍有害）。
- H6 每 5 日更新可能保留大部分效果、换手明显下降。
