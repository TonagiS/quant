# POLICY v1 · 仓位管理提案（2026-11-03）

**状态**：提案，**未接线**。`live/shadow/RULES_v2.md` 是当前规则（v1 已归档）；paper 按 `s2` / `vt15` 双账本成交，VT15 仍属观察臂。
**依据**：`position/PREREG.md`、`position/README.md`、`runs/2026-11-03_POS-01/`。
**性质**：同一批数据（2019-08-13~2026-11-02，ext/base ETF，单边 5bp），不是样本外。

## 1. 规则

### 1.1 信号层（不变）
沿用 shadow v1：
- 有效标的：bar≥150、mom120/vol20 非空；
- 候选：`rm` 非空且 `close > MA60`；
- 目标：`rm` 前 5；权重 `1/vol20` 归一；
- 每 5 个交易日调仓；收盘信号、次日收盘成交（回测口径）。

### 1.2 总敞口（新增）
```
vol60 = 过去 60 个交易日 S2 日收益的年化标准差（至少 40 个样本）
expo  = min(1.0, 0.15 / vol60)          # 目标年化波动 15%，不加杠杆
```
- 样本不足 40 日：`expo = 1.0`，日志标 `warmup=true`（与当前满仓一致，不做无依据的缩放）。
- 回测主口径是每日更新敞口；每 5 日更新的 VT12E5 结果不差（卡玛 0.91/0.72），policy 选"5 日调仓日更新"以省操作，两次调仓之间敞口不变。
- 现金收益不计（实盘可计息，是额外缓冲）。

### 1.3 单票上限（新增）
- 在"股票仓位"内单票上限 **40%**：逆波动权重算出后，超过 40% 的部分按比例分给未触顶的名字；全部触顶则留现金。
- 折算到总资产：单票 ≤ `40% × expo`（expo=63% 时约 25%）。
- 目的：砍掉"候选 <5 只时单票 100%"的尾部；回测代价约 0~0.3pp 年化（探索性，未预登记）。

### 1.4 明确不做
- 不做回撤节流（-10/15/20%）——卡玛 0.25/0.17，显著差于固定同仓位；
- 不做净值均线、120 日现金闸门——降回撤但砍收益，卡玛不升；
- 不做固定/均线止损——-12% 止损几乎没用，跌破 60 日线止损卡玛 -0.18/-0.10；
- 不做 Kelly——半 Kelly 卡玛 0.08/0.11，回撤反而更大；
- 不加杠杆、不做空；现金不融资。

## 3. 执行

- **时点**：14:30 计算信号与敞口（用上一交易日收盘的 vol60），14:50~15:00 成交；与现有影子流程一致。
- **成本**：按单边 5bp 估；VT15 双边换手约 23~26 倍/年，成本约 1.2~1.3pp/年。
- **最小交易**：按 100 份整数倍；单笔金额 < 总资产 0.5% 可跳过（未回测，仅操作便利，需记录）。
- **现金**：留出下月固定费用与 1% 缓冲，不参与计算。

## 4. 监控（每周/每月）

| 指标 | 目标/阈值 | 处理 |
|---|---|---|
| 实现波动（20 日年化） | 15% ± 3pp | 超出只记录，不临时改参数 |
| 平均敞口 | 55%~75% | 长期偏离→检查 vol60 口径 |
| 单票最大权重 | ≤ 40%×expo | 超限→检查 cap 代码 |
| 双边换手 | ≤ 30 倍/年 | 超限→检查是否日更过频 |
| 成本 | ≤ 1.5pp/年 | 超限→降频或谈佣金 |
| 与回测跟踪差 | 月度 ±2pp | 连续 3 月超→暂停复核 |

## 5. 失败模式

1. **波动估计滞后**：波动率跳升时敞口下降发生在回撤之后，不能防第一根大阴线；这是保险成本，不是 bug。
2. **牛市让渡**：2020/2025 这类高波动上涨，敞口被压，收益低于满仓；回测里 2025 年 29.3% vs 35.0%（VT12）。
3. **单一事件依赖**：测试段改善主要来自 2026 年回撤，不能外推为"每年有效"。
4. **ETF 溢价/流动性**：QDII 与冷门 ETF 的溢价未建模；实盘用限价单。
5. **暖机期**：前 40~60 日按满仓，若恰逢大跌没有保护；可用等权指数波动做临时近似（本提案不采用，避免未验证规则）。
