# SIG-01 跨资产适配 / 长周期动量（2026-11-04）

## 1. 扩池归因（`work/pool_attrib.txt`）

| 项 | 52 只 | 69 只 |
|---|---|---|
| 全池等权持有 | 8.49% / 0.23 | 8.31% / 0.26 |
| S2 原样 | 11.43% / 0.36 | 1.44% / 0.03 |
| S2 等权权重 | 10.26% / 0.27 | 3.47% / 0.06 |
| 去掉 60 日线过滤 | 9.57% / 0.27 | 3.11% / 0.06 |
| 波动归一动量 | 8.88% / 0.28 | -1.86% / -0.04 |

结论：池子本身没变差（等权几乎不变），崩的是"动量跨资产排序"；换权重、去趋势、波动归一都救不回来。
新增品种 2022 年占入选 45%（A 股跌、商品/债强），2023 年切换回股票，来回两次成本吃光。

## 2. 换信号能不能救扩池（`work/cross_asset_test.txt`）

| 配置 | 年化 | 卡玛 | 换手 |
|---|---|---|---|
| 69 只 V1 基线 | 1.44% | 0.03 | 29.4x |
| 69 只 V2 长周期(120/250)+VT15 | 10.05% | 0.27 | 18.9x |
| 69 只 V3 类别配额(A3+非A2)+VT15 | 10.52% | 0.26 | 21.7x |
| **52 只 V2 长周期+VT15** | **16.03%** | **0.70** | 17.0x |
| 52 只 V1 基线+VT15 | 14.32% | 0.58 | 19.6x |

结论：扩池即使换长周期信号也追不上原池；**但长周期动量在原 52 池上更好**。

## 3. 长周期信号的稳健性（52 池，场外分档）

| 配置 | 年化 | 回撤 | 卡玛 |
|---|---|---|---|
| 现用 20/60/120 reb10 VT12 | 13.15% | -22.51% | 0.58 |
| 长周期 reb10 VT12 | **15.42%** | **-20.81%** | **0.74** |
| 长周期 reb10 VT15 | 16.03% | -22.95% | 0.70 |
| 长周期 reb14 满仓 | 15.71% | -37.46% | 0.42 |
| 现用 reb14 满仓 | 11.27% | -41.01% | 0.27 |
| 长周期 reb5 VT15 | 9.21% | -25.86% | 0.36 |
| 现用 reb5 VT15 | 11.43% | -25.34% | 0.45 |

三段卡玛：现用+VT15 = 0.59/0.28/1.38；长周期+VT15 = 0.78/0.27/1.22

## 结论

1. **池子维持 52 只**（扩池在任何信号下都不占优）。
2. 长周期动量（120/250 日排名）值得立项验证，但**必须配慢调仓**（reb10~14）；reb5 反而更差，说明它是慢信号。
3. 证据强度：训练段更好、验证段持平、测试段略差；仍是同批数据的自由度，**不能直接改实盘**，应走预登记（分段 + bootstrap + 参数扰动）后再决定。
4. 下一步：`POS-04` 预登记（长周期动量 vs 现用，52 池，reb10/14，VT12/15），跑 5 条判据。
