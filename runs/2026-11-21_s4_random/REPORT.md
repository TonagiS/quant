# S4（同板块最多 2 只）能打过随机持仓吗？——随机组合零假设检验（2026-11-21）

规则见 `FREEZE.md`（回测前冻结，commit a2024c7）。口径同 components：总收益、PIT 池、delay=1、只做多、不加杠杆、5bp（另报 20bp）。每个零假设 1000 个种子，每次调仓用随机分数代替动量得分，其余流程完全一样（1/vol20、VT15、成本、涨跌停处理）。复现校验：S4 0.393 / 0.347 / 0.625，在位 0.217 / 0.291 / 0.457，与 components 一致。不是投资建议。

## 一句话结论
- **S4 显著打过"同约束随机"（N1）**：卡玛的经验 p 值是 W2013 0.004、W2017 0.025、W2019 0.012（20bp 时 0.002 / 0.001 / 0.001）。按预登记判定为"**打过随机（显著）**"。
- **在位 S2+VT15 在 5bp 下打不过它自己的随机零假设（N3）**：p = 0.59 / 0.27 / 0.10。W2013 在位的卡玛（0.217）还低于随机中位数（0.236）。只有到 20bp 时（p = 0.12 / 0.03 / 0.02），在位才略好于随机，主要是因为随机组合换手更多、受成本伤害更大（推断，没有记录随机组合的换手）。
- **板块上限本身不赚钱**：随机 + 上限（N1）的中位数在 W2013、W2017 反而低于随机无上限（N3），卡玛中位 0.207 vs 0.236、0.178 vs 0.228；只在 W2019 略高（0.313 vs 0.285）。所以 S4 比在位多出的部分，**基本不能用"上限本身"解释**（解释比例 −16% / −90% / +17%）。真正起作用的是"**动量排序 + 板块上限**"的组合：上限去掉了动量前几名扎堆在同一板块的问题。
- **MA60 过滤值很多钱**：同样有板块上限，加过滤（N1）比不加（N2）的随机中位卡玛高 0.12–0.25。纯随机、无过滤的组合（N2）中位年化只有 1.6–3.6%。

## 3. 解读
1. **S4 的选股确实比随机好**，而且好得稳定：三个起点窗口都在 97.6%–99.7% 分位，2018 年、2021–24 年、2023 年以来也都在 94% 分位以上。
2. **2015 年是例外**：S4 只在 4.6% 分位，在位也只在 1.6% 分位。那年动量 + VT15 在牛市里减仓、追高，被随机组合甩开；这是 VT15 和动量在 2015 年的共同弱点，S4 没有修好。
3. **在位的动量排序在 5bp 下跟随机分不出来**：W2013 起点甚至低于随机中位数，说明原来"前 5 名动量"带来的增量很小，扎堆同一板块的问题抵消了它。加上板块上限以后，动量才开始体现价值。这和 components 的结果一致（S4 是唯一明显改善卫星的组件）。
4. MA60 过滤是这套卫星里最"实在"的一环：同样随机选，有过滤的中位卡玛高很多。

## 4. 局限
- **多重比较**：S4 是从 components 的 13 个判定臂里挑出来的。这个检验回答的是"给定这些约束，S4 的排序是否比随机好"，**不能消除"从多个组件里挑中它"的选择偏差**。按 13 次比较做 Bonferroni 修正，门槛是 0.0038，W2013 的 0.004 刚好在线上，W2017、W2019 不过。累计约 1500 次试验时，components 里 S4 的 DSR 是 0.09。
- 随机方法是"随机排序 + 贪心上限"，不是在所有合规组合上严格均匀抽样。
- 没有记录随机组合的换手。随机组合每次调仓几乎全换（推断），所以 20bp 下的差距有一部分是换手差，不全是选股能力。
- 三个窗口共用 2019 年后的路径；2025 年后不是留出样本；PIT 池没有退市品种；板块分类粗（宽基、跨境各算一个）。

## 5. 结论与建议（不是投资建议）
- 预登记判定：**S4 打过随机（显著）**；在位 S2+VT15 在 5bp 下对随机是"混合 / 无明显差别"。
- 这支持把 S4 当作比在位更有根据的卫星版本，但它仍是事后从多个组件里选出来的，所以维持原建议：**冻结 S4，与在位并行做影子观察 6–12 个月**，不直接替换实盘。
