# full_rebuild 预登记（2026-11-21，跑结果之前冻结）

**问题**：不在冠军上增量加层，而是把各层候选放进一个联合网格从零重搭。要回答：哪些层、哪些选项要紧？用前段选出来的配置，在后段（以及反向）表现如何？有没有东西在样本外胜过冠军？
数据：总收益面板 v2；top5、10 日滚动再平衡、延迟 1 日、成本 5/20bp。**全部为样本内研究**；时间切分只是「伪样本外」，因为各层候选本身是在全样本研究中提出来的。

## 网格：全因子 4 × 3 × 3 × 4 × 2 × 4 × 4 = 2304 个配置（不抽样）× 2 档成本
| 层 | 选项 |
|---|---|
| L0 市场状态 | NONE / TREND_SWITCH / TREND_BEAR30 / BREADTH_BEAR30 |
| L1 池 | BASE / P12_HYST60 / P10_LOWCORR |
| L2 大趋势过滤 | NONE / T120（120 日收益 > 0 且 MA120 高于 20 日前）/ W30（周收盘 > 30 周均线） |
| L3 小趋势/选股信号 | S2 / RAM / DONCH / TSM（定义同 combo3） |
| CAP 板块上限 | CAP2 / NOCAP |
| L4 仓位 | VT10 / VT15 / ERC_VT15 / BRD_VT15（池内宽度乘数，定义同 combo3） |
| L5 离场 | NONE（同入场：调仓时掉出前 5 即卖）/ HYST10（排名 > 10 才卖）/ TS12（建仓后高点回撤 12%）/ TIME30（30 日无新高） |

L0 的含义：
- **TREND_SWITCH**：大盘（sh510300 TR）> MA200 且 MA200 上行 = 牛，用配置本身；震荡用同池、同大趋势、同板块、同离场的 RAM+VT10；熊用震荡袖子 × 0.3。当配置为 DONCH+VT15 时，与 framework_layers 的 SWITCH 逐日一致（已核对，最大差 0.0）。
- **TREND_BEAR30**：大盘趋势判熊时，敞口 × 0.3。
- **BREADTH_BEAR30**：池内收盘 > MA60 占比 < 0.35 时，敞口 × 0.3。

执行与成本约定同 framework_layers（t 收盘定，t+1 成交，t+2 生效；换袖子按全卖全买）。离场层、L2 过滤由 work/fw_engine.py 实现。已核对：S4 格（NONE|BASE|NONE|S2|CAP2|VT15|NONE）、冠军格（NONE|P12_HYST60|NONE|DONCH|CAP2|VT10|NONE）以及它们的 BRD_VT15 与 combo3 缓存逐日一致。

## 协议
**(1) 时间切分选择（主结果）**
- 切分 A：在 2014‑06‑01 ~ 2019‑12‑31 上选，在 2020‑01‑01 ~ 2026‑11‑13 上测。切分 B 反过来。
- **主规则**：20bp 下，IS 段内滚动中位卡玛最高者。滚动起点为段内每月第一个交易日，窗口到段末，至少 3 年：A 的 IS 有 31 个起点，OOS 有 47 个起点。
- **副规则**：20bp 下 IS 段整段卡玛最高者。
- 测试对象：IS 第 1 名和 IS 前 10 名，原样不改。前 10 报告两种口径：指标平均值，以及 10 个配置日收益等权平均后的组合。
- 报告：OOS 滚动中位卡玛、整段卡玛、CAGR、MDD，以及在 2304 个中的 OOS 排名；对比 S4、冠军和宽基 VT15 在同一 OOS 段的表现，5bp 和 20bp 都给。
- 注意：冠军是用全样本挑出来的，对它的比较对冠军有利。

**(2) 主效应与交互（方差分解）**
- 全期（2014‑06 起）卡玛、滚动中位卡玛、对 S4 中位差、MDD、CAGR，以及两段各自的卡玛。
- 每个因子的平方和占比、21 个两两交互的占比，剩余部分为三阶及以上交互。全因子平衡设计，分解是正交的。
- 另报告每个选项的边际均值、与总均值之差，以及该选项进入前 10% 的比例。5bp 和 20bp 都给。

**(3) 试验数校正**：PBO‑CSCV（S = 16，12870 种划分，IS 按夏普选）和 DSR（N = 2304），5bp 与 20bp 都给；同时给出 S4 和冠军的 DSR。

**(4) 稳健集**：对 S4 用滚动起点判据（114 个起点中 ≥ 70% 改善、中位差 > +0.05、4 段中 ≥ 3 段更好），5bp 和 20bp 都通过的配置。报告个数，以及各选项在稳健集中与在网格中的占比对比。

**(5) 卫星**：选 20bp 全期滚动中位卡玛前 3 名、两个切分方向的 IS 第 1 名（主规则），再加上冠军和 S4。各作 40% 卫星配 C3 60%，对比 C3+S4、C3+冠军、C3+宽基 VT15，5bp 和 20bp。
