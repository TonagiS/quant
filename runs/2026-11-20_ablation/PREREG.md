# PREREG · 消融：动量选股 / 逆波动权重 / VT15 择时（2026-11-20，跑数之前写并冻结）

**动机**：现在跑的三本账 = 动量选 5 只（选谁）× 逆波动权重（怎么配）× 敞口（何时加满）。
已知"宽池上打不过等权"，但**没做过逐层拆解**：到底是选股拖累、还是权重拖累、还是 VT 择时没用？
本实验只改一层、其余保持，看每层各自的贡献。

**性质**：同一批历史数据上的分层归因，**不是样本外**。7 个臂一次跑完，不挑最优、不网格搜索。
**不改任何实盘/影子盘规则**，纯研究。

## 七个臂（一层之差）

| 臂 | 选股 | 权重 | 敞口 | 说明 |
|---|---|---|---|---|
| A 等权满仓 | 全池（bar≥150） | 等权 | 100% | 真正的"无策略"基座，带 5bp 成本 |
| B 等权+VT | 全池 | 等权 | VT15 | **基座上直接加 VT，回答"VT 在等权基座上还有没有用"** |
| C 等权固定 65% | 全池 | 等权 | 恒定 65% | 与 B 的平均暴露匹配的对照（区分"择时"与"单纯降仓"） |
| D 动量 k5 满仓（S2） | 动量前 5 | 逆波动 | 100% | 现有实盘臂一 |
| E 动量 k5 + VT（VT15） | 动量前 5 | 逆波动 | VT15 | 现有实盘臂二 |
| F 动量 k5 等权满仓 | 动量前 5 | 等权 | 100% | 拆出"逆波动权重"单独的贡献 |
| G 动量 k5 等权 + VT | 动量前 5 | 等权 | VT15 | 辅助臂：去掉逆波动后 VT 还剩多少 |

**A/B/C 的"全池"= 所有 bar≥150 且当日有价的标的，不套 MA60 过滤**（MA60 是选股规则的一部分，归 D 那一层）；
调仓节奏与 D/E 完全一致（reb=10、rolling、delay=1、5bp），保证唯一差异是列出的那一层。

## 冻结参数

```
k=5（D/E/F/G）  reb=10  reb_mode=rolling  min_names=8
成本：buy_cost = sell_cost = 0.0005（单边 5bp）  delay=1
VT：VolTarget(target=0.15, window=60, every=1)，敞口 = min(1, 0.15/vol60)
动量排序：rm = rank(mom20)/rank(mom60)/rank(mom120) 均值，降序取前 5；候选需 close > MA60
A/B/C：候选 = 全部有效标的，等权
C：Fixed(0.65)
```

## 判据（风险型为主，事前写死）

基座是"等权满仓 A"，逐层加东西，判据全部是**卡玛/回撤**（降风险族不许用收益型判据冤杀）：

- **AB1（VT 在等权基座上是否有效）**：
  `卡玛(B) − 卡玛(A) ≥ +0.05` 且 `回撤(B) 比回撤(A) 浅 ≥ 5pp`，**两个池都要满足**。
- **AB2（VT 是"择时"还是"单纯降仓"）**（关键对照）：
  `卡玛(B) ≥ 卡玛(C) + 0.03`，两个池都要满足。仅 AB2 成立才算 VT 有择时价值；
  AB1 成立但 AB2 不成立 → 判定为"等权基座加 VT 只是降仓"，写进结论但不算择时。
- **AB3（动量选股这一层的净贡献）**：
  报 `年化(D) − 年化(A)` 与 `卡玛(D) − 卡玛(A)`。
  判据：宽池上 `年化(D) − 年化(A) < 0`（预期负）；ext 池上 `> 0`（预期正）。
  任一方向不符，就如实写"动量选股的方向随池子变化，不能外推"。
- **AB4（逆波动权重这一层）**：
  `卡玛(F) vs 卡玛(D)`、`卡玛(G) vs 卡玛(E)`；判据：逆波动相对等权 **卡玛差不小于 −0.03**（不许明显变差），
  且若卡玛差 ≥ +0.03 记为"有正向贡献"。
- **AB5（两层叠加的残差）**：
  `卡玛(E) − 卡玛(B)`：既然 VT 已单独测过，这里看"动量选股在 VT 之上还能不能加"。

判定规则：AB1/AB2 写死阈值；AB3/AB4 只判方向与阈值，**不做事后调参**。
所有差值同时报 bootstrap（月度 stationary bootstrap，2000 次，p=1/6）90% 区间的中位数与下沿，供参考。
