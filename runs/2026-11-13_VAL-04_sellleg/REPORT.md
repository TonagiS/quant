# VAL-04 · 拆开用：买入腿=VT15，卖出腿=估值高估分批减仓

2026-11-13 · 脚本 `position/val04_sellleg.py` / `work/val04_placebo.py` · 产物 `summary_all.csv` / `criteria.csv` / `bootstrap.csv` / `meta.json`

## 规则

- **买入腿**：不看估值，敞口 = VT15（clip(15%/60 日已实现波动, 0, 1)），随时可建仓。
- **卖出腿**：沪深300 PE 分位 **≥80 连续 60 个交易日**才启动，之后每 20 个交易日减 25% 仓位；
  分位回落到 **<70** 才分批加回（每次 +25%，同样 20 日冷却）——滞回，防止在偏高区间反复打折。
- 总敞口 = min(VT15, 卖出腿)，成本 5bp 单边。

三套参数：S1(80/60 日/每次 25%)、S2(85/60 日/33%)、S3(80/40 日/20%)；对照：VT15、S2 满仓、VT15×简单红灯(>80 直接半仓)。

## 解读

1. **卖出腿是保险，不是 alpha**：37 只池里年化 −0.09pp（等于白送），换来回撤 −34.9% → −27.8%。
   bootstrap 也印证——CAGR 差 90% 区间 [−1.28%, +1.03%]（中位 −0.07%），收益维度几乎没变化；
   Sharpe 差 [−0.017, +0.022] 跨 0，因为 Sharpe 不看回撤深度。
2. **好处全部来自 2008**：long+stocks 是唯一含 2007 泡沫破裂的样本；2010 起的 long 池、2019 起的 ext 池都没有"估值泡沫 → 崩盘"的事件，
   所以回撤零改善，只剩"牛市里少赚"的代价（ext −1.9pp）。
3. **样本事件数 n=1**：不能把 7.2pp 当成"每次泡沫都能省 7pp"的期望值；它的真实含义是"在最坏的那次里少亏两成"。
4. 之前 VAL-01 的"连续乘子"版本失败、这个"有持续性过滤的卖出腿"反而有效，差别就在：
   前者在 2019-2026 的 23% 红灯天数里天天打折，后者只在分位连挂 60 天时才动手，全年触发日只有 12%。

## 结论

- **可以留，但要按"保险"来定价**：正常年份每年让渡 0~2pp 年化，换取泡沫破裂时少亏 7pp 回撤。
- 实盘（ext 池，2019-2026 无泡沫）这几年它只会拖 1.9pp 年化、回撤一点不省 —— 如果只上实盘池，**不值得**。
- 若目标里包含"穿越一次完整泡沫"，它值得挂在 VT15 上，参数用 S1（80/60 日/25%/滞回 70）。
- 下一步可做的：把"触发"从单一的沪深300 分位换成"沪深300 + 中证500 + 创业板分位取最高"（更贴近 2015 那种结构性泡沫），
  这样 2015 段也可能被覆盖；或者用 long+stocks 2007 起 + 2015 双泡沫做一次分段验证。
