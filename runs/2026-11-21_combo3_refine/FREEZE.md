# combo3_refine 预登记（2026-11-21，跑结果之前冻结）

对象：combo3 最优 **B = P12_HYST60 | DONCH | CAP2 | VT10**（runs/2026-11-21_combo3）。数据：总收益面板 v2（trfix 7b3ef1d 之后）。
已核对：本脚本重跑 B 与 combo3 缓存逐日完全一致（最大绝对差 0.0）；无改动的权重重放 vs 引擎最大差 6.9e−18。
除第 1 部分的"样本外"段落外，**全部为样本内结果**。

## 第 1 部分：真·分段样本外（不新增试验，只重做 combo3 的选择过程）
combo3 的 768 条日收益（384 组合 × 5/20bp）全部因果计算（滚动窗口、月末 PIT 池次日生效、VT 只用过去），所以截取某一窗口的收益 = 只用该窗口及以前的数据重跑。
**选择规则**（与 combo3 相同，只把窗口收窄）：IS 窗口 [a, b]，滚动起点 = a 到 b−3 年之间每月首个交易日，卡玛从起点算到 b；按对 S4 的中位卡玛差降序排序，同分看滚动中位卡玛（S4 本身不参选）。
- **A 正向**：IS = 2014‑06 ~ 2019‑12（起点 2014‑06 ~ 2016‑12），取第 1 名与前 5 名原样拿到 OOS = 2020‑01‑02 ~ 2026‑11‑13。
- **B 反向**：IS = 2020‑01 ~ 2026‑11（起点 2020‑01 ~ 2023‑11），OOS = 2014‑06‑03 ~ 2019‑12‑31。
- 报告：OOS 的 CAGR / MDD / 卡玛 / 夏普，对照 S4 与宽基+MA60+VT15 同期；IS 第 1 名在 384 个中的 OOS 卡玛排名、OOS 内滚动对 S4 中位差及其排名（OOS ≥4.5 年用 3 年起点，否则 2 年）；combo3 全样本最优在 IS 排名中的位置。前 5 名等权（日再平衡近似）也报。
- **C 逐年扩展窗口重选**：Y = 2017…2026，每年初用 2014‑06 ~ (Y−1)‑12‑31 选第 1 名（起点至少 2 年，到 IS 末），持有一年；换策略时按两边卫星敞口扣一次单边成本（卖出旧敞口 + 买入新敞口）。比较 2017‑01 ~ 2026‑11 的链式结果 vs S4、宽基VT15、combo3 全样本最优（后者是样本内）。
- 5bp、20bp 各做一遍。

## 第 2–6 部分：在 B 上逐项改一处（单因素），15 个变体（含 B 本身）
| 代号 | 改动 |
|---|---|
| DONCH_AVG | 通道位置 4 组窗口（40/80、60/120、90/180、120/250）各组两窗口排名平均，再在 4 组间平均（缺窗口的组跳过）；候选条件不变（收盘 > 60 日通道中线） |
| BLEND3 | DONCH、RAM、S2 三个分数各自截面百分位的均值；候选 = 三个信号候选条件过半（S2/RAM 都是收盘>MA60，所以等价于收盘>MA60） |
| VOTE2 | 三个信号各自（自身候选 + 板块上限）的前 5；被 ≥2 个信号选中才可入选，按 BLEND3 分数排序；不足 5 只留现金 |
| BUF8 / BUF10 | 排名缓冲：在位持仓仍在前 8 / 前 10 名就不换出（engine buffer_n） |
| BAND2 / BAND5 | 不交易带：执行日对已持有且仍在目标里的名字，权重调整 < 2pp / 5pp 就不调（新进、清仓照做） |
| REB15 / REB20 | 每 15 / 20 个交易日再平衡（VT 调整间隔同步改为 15 / 20） |
| VT8 / VT12 | 波动目标 8% / 12% |
| VT10_REGIME200 | 只在沪深300 全收益代理（H00300）收盘 < MA200 时做 VT10，否则仓位 1（每 10 日判断） |
| TRAIL12 | 单只持仓自买入后最高收盘回撤 ≥ 12% 当日收盘卖出 |
| DCH20_EXIT | 单只持仓收盘 < 前 20 日最低收盘当日收盘卖出 |
止损/不交易带用权重重放实现：port_t = Σw_{t−1}·r_t − 成本·Σ|Δw|；止损后只在引擎下一次调仓（目标权重有变化）时按目标重新买入；跌停日卖不出顺延。

## 判据（与 combo3 / pool_variants 相同）
起点 2014‑06 ~ 2023‑11 每月首个交易日（114 个，各 ≥3 年），4 段 2014‑16 / 2017‑19 / 2020‑22 / 2023‑26，5bp 与 20bp。
对 B、对 S4、对宽基VT15 分别算：卡玛改善起点占比 ≥ 70%、中位卡玛差 > +0.05、4 段中 ≥3 段更好；三条全满足 = 通过。
**组件通过**：一般组件 = 5bp 与 20bp 都对 B 通过；换手类（BUF/BAND/REB）= 20bp 对 B 通过且 5bp 对 B 中位差 ≥ −0.05。

## 组合版 REFINED
只用通过的组件：每类（signal_avg / signal_blend / turnover / vt / stop）最多取一个，类内按对 B 中位差最高者（换手类看 20bp，其余看 5bp）；DONCH_AVG 与混合信号都通过时用混合信号。没有组件通过 → 不做 REFINED，结论是保留 B。
REFINED 同样按上面判据对 B、对 S4 评估（注意：组件挑选会带来额外选择偏差）。

## 卫星
每个变体与 REFINED 作 40% 卫星 + C3 60%（月末再平衡），对 C3+B、对 C3+S4，同一判据，5/20bp。
