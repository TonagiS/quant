# P1 / P3：组合层叠加实验（2026-11-16）

基线口径：`Config(reb=5, k=5, cap=1.0, rule=VolTarget(0.15, 60, every=5))`，`load_panel("ext")`，
5bp 单边，权重取 `w_hist[i-1]`（无前视）。本脚本重算得到 17.1% / −16.4% / **1.040**
（与 P2 的 16.25% / 0.984 差在首日与边界处理，属同一口径，比较只在同一脚本内进行）。

叠加臂定义：
- **质量Q**：总敞口 × `clip(0.5 + 0.5 × 持仓中"收盘>MA60"的占比, 0.5, 1)`
- **单支快线**：每只权重 × 单支定稿策略（20 日动量破位→年线上行减半/否则清仓，缓冲 1%；
  × `clip(0.15/vol60, 0.4, 1)` × 趋势衰减 T0/T1=1、T2=0.85、T3=0.6、T4=0.5）
- **快线半仓版**：`0.5 + 0.5 × 单支快线`（更温和，敞口损失更小）
- **等敞口对照**：把 VT 目标抬高，尽量让两臂平均敞口接近

再乘一遍只是多交易。

VT 压不住。叠加单支择时同样为负。**不建议把 k 降到 2。**

## 3. 为什么叠加在组合层总是负（三次实验一致）

1. **重复**：VT15 已在按组合波动砍总仓，单支择时是同一个动作的第二种实现。
2. **样本不同**：单支研究的正增量来自"含弱标的"的全样本（89 只）；S2 选出的 5 只本来就是强势标的，
   择时空间被吃掉。
3. **成本**：叠加臂换手 17.5~23.2，与基线 25.8 同量级，但收益掉一半——whipsaw 成交在低效时点。
4. **集中度**：k 越小，越依赖单票，任何择时错误都被放大。

## 4. 结论与后续

- P1、P3 都不上线；组合层维持 S2(k=5) + VT15。
- **"入场门票"也测了，同样是负的**（0.827 vs 1.040；k=2 上 0.554 vs 0.591）——单支层进组合这条路基本封死，
  连"只在建仓日把关"都因为错过反弹起手而掉卡玛。原因：门槛把"抄底买入"滤掉，而 S2 的动量池本来就偏右侧，
  先涨了一段才进榜，等它 `mom20>0` 才建仓反而买在更贵的位置。
- 如果确实要做集中持有（k=2），必须先加"单票硬止损"或"行业上限"，否则尾部风险不可控。
