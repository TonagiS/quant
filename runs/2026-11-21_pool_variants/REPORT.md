## 3. 判定
| 策略 | 通过（5bp） | 稳健通过（5bp + 20bp） |
|---|---|---|
| S4 | 无（最接近的 P12_HYST60：87.7% / +0.045 / 3，中位差 0.005 不到门槛） | 无 |
| S2+VT15 | **P12_HYST60**（100% / +0.110 / 3） | **P12_HYST60**（20bp：100% / +0.080 / 3） |
| C3 60%+S4 | **P12_HYST60**（100% / +0.141 / 3） | 无（20bp：87.7% / +0.032 / 3，中位差不到门槛） |

**最佳池：P12_HYST60（自加的"滞后带"）。** 上月成员只要仍在成交额前 60 就保留，再补满 40。
- 池内每月新进约 0.65 只，BASE 是 2.32 只；但 S4 自身的年换手只从 21.2 倍降到 20.3 倍。
- 全期（2014-06 起，5bp）：
  - S4：11.3% / −27.7% / 0.408，**低于 BASE 的 0.433**；
  - S2+VT15：9.8% / −32.9% / 0.298（BASE 0.237）；
  - C3 60%+S4：10.0% / −12.7% / 0.787（BASE 0.779）。
- **分段很不均匀。** 2014-16 段明显更差，Δ卡玛 S4 −0.703、S2+VT15 −0.601、C3 60%+S4 −0.834；后三段都为正。由于滚动起点都在 2014-06 之后、终点相同，正差占比主要由 2017 年后决定。

其他发现：
- **费率/质量倾斜（P3）、去重（P1）、绝对流动性门槛（P2）、剔除跨境和商品（P8）、板块均衡（P6）、更长上市期（P9）都明显更差。** 比如 P8 的 C3 60%+S4 中位 Δ −0.349，P3_FEE40 S4 −0.161。
  - 剔除跨境和商品伤害最大，说明 S4 的收益里有相当一部分来自跨境和黄金类 ETF。
- **S2+VT15（不限板块）在"更分散"的池上普遍改善**：P5_N60、P10_LOWCORR、P6_SEC3、P7_ATTN、P9_SEASON500 都是 100% 起点为正，但只有 1–2 段为正，中位 Δ +0.04 到 +0.13。叠上板块上限变成 S4 之后，这些改善全部消失甚至转负。说明这些池改善的是"板块集中"问题，而 S4 的板块上限已经解决了它。
- P7_CROWDX（剔除成交额激增 > 3 倍）几乎无影响，略负：S4 −0.036。

## 5. 结论与建议
- **不改池。** 只有 P12_HYST60 过了预设判据，而且只在 S2+VT15（稳健）和 C3 60%+S4（仅 5bp）上过；在主力 S4 上没过，全期卡玛反而更低，2014-16 段显著更差，相对随机池也不显著。可以列入观察，不建议进影子盘。
- 用户关心的主题池（P4）在 2020-10 后看起来不错，但属于事后选择，覆盖太短。
- 试验数：20 个变体 × 3 个策略 = 60（PV-POOL-01）。

## 6. 注意事项
- 114 个起点高度重叠，终点相同，正差占比不是独立证据。
- 费率是当前值，有前视。深市 ETF 没有规模历史，记为中性。跟踪误差没有免费数据，没用上。
- 跟踪指数用的是当前对应关系。
- 宇宙只含当前仍在交易的 ETF，存在幸存者偏差（BASE 同样存在）。
