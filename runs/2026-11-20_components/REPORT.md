# 新组件逐个加入测试：核心 C1–C3 / 卫星 S1–S4 / 风控 R1–R2 / 全加 / 只加通过的（2026-11-20）

规则见 `FREEZE.md`（回测前冻结，commit 4fc079a）。总收益口径、PIT 池、单边 5bp（另报 10/15/20bp）、delay=1、只做多、不加杠杆、现金收益 0。数据到 2026-11-13；2025 年后不是留出样本。三个起点窗口共用 2019 年后的路径，不是独立证据。不是投资建议。

复现校验：DIV-IV W2013 8.2% / −8.3% / 0.993，S2+VT15 7.9% / −36.6% / 0.217，MIX80/20 0.905，与上两次一致。

## 一句话结论

1. **按预登记字面判定，13 个判定臂里有 9 个"采用"**：C1、C2、C3、S2r、S4、R1@S2+VT15、R2@S2+VT15、ALL-IN、ADOPTED-ONLY。**但一半以上是靠"把风险换成短债"过的线，不是真的更好**：
   - C1：短融占 73%，年化 8.2% → 4.4%。
   - C2：国债占 68%，年化降到 6.5%。
   - ALL-IN：年化 8.4% → 5.6%。
   - ADOPTED-ONLY：年化降到 5.4%。
   
   不加杠杆时，卡玛标准会奖励"降风险也降收益"。这几臂相对在位的超额收益都是负的，超额夏普为正的概率不到 1%。这个标准漏洞是我冻结时没堵上的。
2. **同时提高收益、降低回撤的只有 C3 和 S4，S2r 弱一些**：
   - **C3 股债性价比**：年化 8.2% → 8.8%，卡玛三窗口都略高（+0.01 至 +0.04），任何成本下都成立。但幅度小：DSR 按累计 1496 次试验算是 0.94，不到 0.95。
   - **S4 行业上限（同板块最多 2 只）**：卫星年化 7.9% → 9.8%，回撤 −36.6% → −24.9%，卡玛 0.39 / 0.35 / 0.63（在位 0.22 / 0.29 / 0.46），20bp 下也是 3/3。但按 1496 次试验算 DSR 只有 0.09，统计上不显著。
   - **S2r 跳过最近 5 日**：2/3 窗口胜出，W2019 输，DSR 低。
3. **R1/R2 加在 S2+VT15 上过线，但收益降了**：
   - R1 超额夏普 −0.07，R2 是 −0.22。R2 在 10bp 以上只剩 1/3 窗口。
   - 加在 80/20 上：R1 从没触发过，因为组合回撤一直不到 15%；R2 不过。
4. **S1 动量质量和 S3 缓冲不采用**。**S3 把卫星换手从 20.0 降到 16.6（−17%），但每个成本档的卡玛仍然只有 1/3 窗口赢在位**，换手降下来的部分抵不过少换带来的损失。
5. **建议**：用来"多赚少亏"的只有 C3（核心）和 S4（＋S2r，卫星）。我事后把它们组合成"C3 核心 + S2r+S4 卫星、80/20"，结果是 9.3% / −9.5% / 0.98、0.98、1.24（在位 80/20 是 8.4% / −9.2% / 0.91、0.94、1.12）。这个组合是看了结果才挑的，不能算已验证，最多冻结进影子观察。

**实现说明（偏离冻结文字）**：冻结写的是用 engine 的乘法迭代求 ERC。实测在协方差含负值（股债负相关）时它**不收敛**：风险贡献不相等，还会出现负贡献，例如 2020-06 国债的风险贡献是 −0.53 倍均值。ERC 的定义（等风险贡献）不变，求解器改用 Spinu 凸形式的循环坐标下降，所有日期的风险贡献都相等。按原算法跑出的数字放在 `reference_results_erc_multiplicative.csv`：C2 是 0.469 / 0.433 / 0.537，不采用；ALL-IN 是 0.506 / 0.458 / 0.514，不采用。

## 7. 局限
- **标准漏洞**：组合判定只看卡玛，不加杠杆时"换成短债"就能过线。下次判定应预先加一条"年化不低于在位 X pp"，本次不能事后改。
- 代理数据：可转债用中证转债价格指数（与 511380 跟踪的指数不完全相同）；日经用价格指数、日元计，DAX 欧元计，XOP 美元计，都没换汇，与 DIV-IV 里纳指、标普的处理一致；162411 腾讯数据从 2012-06 开始。
- C3 的 PE 从 2011-06 才有，W2013 起点时扩张窗口只有约 1.5 年历史。用的是沪深300 TTM PE 和 10 年国债收益率；分红和盈利口径没有再细分。
- R1 在 80/20 上从没触发过。阈值是事先定的，没调。
- S4 的板块分类用名称关键词，宽基、跨境各算一个板块，比较粗。
- 只有 2026-11 在市的 ETF，没有退市品种；三个窗口共用 2019 年后的路径；2025 年后不是留出样本。
- 多重比较：本次 13 个判定臂加 1 个事后组合，累计已约 1500 次试验。

## 8. 建议（不是投资建议）
1. **不要采用 C1、C2、ALL-IN、ADOPTED-ONLY**，虽然字面上过了。它们靠降低收益换回撤，和"多赚少亏"的目标相反。
2. **C3 可以加到核心上**：收益和卡玛都略好，任何成本下都成立，规则简单、事先定死。但幅度很小（DSR 0.94），预期是小幅改善，不是质变。
3. **S4 是本次最有价值的卫星组件**：回撤浅约 12pp，年化多约 2pp，20bp 下也 3/3。但扣掉累计试验数后不显著。建议冻结进影子观察，不要直接替换实盘。
4. S2r、R1、R2 边际很小或靠降收益过线，不建议加。S1、S3 不采用。
5. 如果要一个"多赚少亏"的组合候选，就用事后组合 **C3 核心 + S2r+S4 卫星、80/20**。它只能和 MIX80/20、纯 DIV-IV 并行做影子观察，不算已验证。
