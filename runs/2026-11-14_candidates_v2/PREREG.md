# 预登记：单支 ETF 候选规则 v2（四臂一次性比较）

- 日期：2026-11-14
- 状态：规则在看到任何结果前冻结，尚未回测
- 用户已批准运行全部四臂。不开网格，不按训练段为品种或状态挑选规则

## 共用口径（与 2026-11-14_fullmkt_single_asset、2026-11-14_layered_v1 完全相同）

单边 5bp；信号日收盘决策，次日收盘成交（delay=1）；只做多、不加杠杆；前复权缓存 `data/cache_ohlc_full/`；同一 951 只截面过滤；训练段至 2022-12-31 只作背景；测试段 2023-01-01 至 2026-11-13；2025 及以后已用过，不称为新鲜留出。
因子：MA200、slope60 = MA200 的 60 日涨跌幅、mom20、vol60 = 60 日年化波动。
慢速组：category == 债券，或 sector == 银行，或 sector == 风格-红利/低波（与 layered_v1 相同）；其余为主动组。

## 对照

- BH：满仓
- A：旧定稿 G1 × clip(0.15/vol60, 0.4, 1.0) × taper(T0/T1=1.0, T2=0.85, T3=0.6, T4=0.5)，全部品种
- B：layered_v1（已跑，作为参照，重算一致即可）

## C. 拼接规则

- 慢速组：layered_v1 慢速规则（收盘 < MA200 且 slope60 < -2% 时 0.5，否则 1.0；MA200 缺失 1.0）
- 主动组：臂 A 原样

## D. 熔断式保险（全部品种同一规则）

- 默认 1.0
- 熔断：收盘 < MA200 且 slope60 < -2%，连续 3 个交易日成立 → 0.0
- 恢复：收盘 > MA200，连续 3 个交易日成立 → 1.0
- 其余日保持前一状态；MA200 缺失时 1.0
- 无波动帽、无 mom20

## E. 自身波动分位缩放（全部品种同一规则）

- pct = vol60 在其过去 750 个交易日（自身历史，至少 250 个有效值，否则 1.0）中的分位（只用当日及以前）
- 系数 = 1.0（pct ≤ 0.70）；0.75（0.70 < pct ≤ 0.90）；0.50（pct > 0.90）
- 再乘臂 D 的熔断开关（0 或 1）
- 无绝对 15% 波动目标、无 mom20

## F. 0/1 长趋势跟踪（全部品种同一规则）

- 进场：收盘 > MA200 连续 3 个交易日 → 1.0
- 离场：收盘 < MA200 连续 3 个交易日 → 0.0
- 其余日保持；MA200 缺失时 1.0
- 无波动帽、无斜率条件、无 mom20

## 判读（事先写明）

主看测试段，同时报告训练段、全样本。每臂报告年化、回撤、卡玛、平均仓位、换手，以及相对 BH 和相对 A 的差值；按大类/板块与焦点主题（科创芯片、半导体设备、机器人、银行、养殖、传媒）分开。

- C 的预期：在慢速组接近 BH，主动组等于 A；全截面中位卡玛应不低于 A 太多，同时慢速组年化拖累消失
- D/E/F：只有在全截面中位卡玛不低于 A，且高波动主题（芯片、半导体设备）年化少赚明显小于 A，才算比旧定稿更好；否则只当作「更高仓位、更弱风控」的另一点
- 不因某一主题看起来最好就为该主题单独选规则
- 七臂一起比较，多重比较下任何单臂优势需在多数板块方向一致才认为可信
