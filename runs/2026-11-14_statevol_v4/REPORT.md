# 状态切换波动帽 A-SV（v4）

## 设置与验证

- 规则：按 `PREREG.md` 冻结执行，只新增 A-SV 一个臂，不开网格。
  - A-SV = G1 × capS × taper。
  - T 处于 T0/T1 时关帽；当日离开 T0/T1 即开帽；开帽后连续 3 日回到 T0/T1 才关帽。
- 口径与面板沿用 v3：
  - 修正总收益，单边 5bp，delay=1，只做多。
  - 面板：长 ETF 190、指数代理 19、2019 起截面 950、跨市场主面板 6、辅助 4。
- 验证：A、A−vol、BH 共 4170 行与 ablation_v3 逐项一致（差 0）。
- 静态对照：k×BH，k 取同窗口平均仓位，事后计算，只用于判读。
- 2023 年后的数据已经看过，不是新鲜留出。不构成投资建议。

## 崩盘第一段（`crash_first_leg.csv`）

本节是诊断，不是预登记判据。

**方法**
- 峰值：各标的满仓在固定日期窗内的最高点。
- 谷底：峰值之后、给定截止日之前的最低点。
- 第一段：从峰值到 A-SV 开帽日的下一个收盘（含 1 日执行滞后）。
- 这一段 A-SV 与 A−vol 相同（帽是关的）。A 已被波动帽压低，只剩 G1 和 taper 在起作用。

| 面板 / 事件 | 峰值→开帽交易日 | 第一段：满仓 / A / A-SV | 全段 MDD：A / A−vol / A-SV |
|---|---|---|---|
| 指数 2008（n8） | 52 | -24% / -9% / -19% | -13% / -30% / -25% |
| 指数 2015（n14） | 42 | -43% / -12% / -28% | -13% / -29% / -29% |
| 指数 2018（n14） | 9 | -10% / -7% / -9% | -11% / -14% / -14% |
| 长ETF 2015（n40） | 17 | -31% / -11% / -25% | -12% / -27% / -28% |
| 长ETF 2018（n68） | 16 | -10% / -7% / -9% | -13% / -18% / -16% |
| 跨市场 2000（n5） | 15 | -17% / -8% / -14% | -16% / -23% / -19% |
| 跨市场 2007–08（n5） | 23 | -13% / -7% / -10% | -11% / -17% / -15% |

**典型标的**
- 沪深300 2015：6/8 见顶，8/20 才开帽，第一段 A-SV -21%，A -10%。
- 中证半导体 2015：7/7 开帽，第一段 A-SV -32%，A -14%。
- SOX 2000：3/10 见顶，8/4 才开帽（102 个交易日），第一段 A-SV -25%，A -10%。
- 2018 年下跌较缓、离开上行较早，第一段差距小（中位差约 1–2pp）。

**结论**
- 在 2008、2015 和 SOX 2000 这类急跌中，A-SV 的回撤主要在开帽之前就已经形成。
- A-SV 比 A 多出的 MDD 中，第一段贡献约 83–96%（2015、2008 指数及长 ETF）。
- 原因：急涨之后 MA200 远低于价格且斜率为正，T 在暴跌初期仍处于 T0/T1，开帽信号明显滞后。

## 采用标准（结果：不采用，继续用 A）

**① 关键年份不劣于 A：未过，8 格全部失败。**
- 7 格因 MDD 深于 A 超过 3pp：
  - 指数：2008 -25 vs -14，2015 -30 vs -13，2018 -14 vs -8。
  - 长ETF：2008 -22 vs -15，2015 -28 vs -12，2018 -14 vs -10。
- 2016 两格因卡玛略低：指数 -1.03 vs -1.02，长ETF -0.42 vs -0.40。
- 2008 年 A-SV 的卡玛反而高于 A（-0.75 vs -0.77；-0.77 vs -0.83），但 MDD 条件不满足。

**② 对同仓位静态对照：过。**
- 指数 +0.140（95%）。
- 长ETF +0.024（59%）。

**③ 跨市场主面板全历史中位卡玛 ≥ A：未过。**
- 0.215 vs 0.220，差距很小。

**处理**
- 按预登记，A-SV 只作为「更高仓位档」记录。
- 仓位介于 A 与 A−vol 之间；回撤在长 ETF、截面、跨市场上介于两者之间，在指数面板上与 A−vol 相当（-41.0 vs -40.4）。
- 卡玛只在跨市场主面板上介于两者之间；在长 ETF、指数和截面上都低于 A 与 A−vol。
- 急跌第一段的回撤与 A−vol 一致。
