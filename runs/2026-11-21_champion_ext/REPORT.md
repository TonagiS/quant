# 冠军在 ext 池上的效果（2026-11-21）

全部为**样本内**研究。ext 是事后挑选的固定 52 只热门 ETF，有幸存者和选择偏差，**结果偏乐观，不能当作可实现预期**。本 run **不用 ext 上的数字决定是否更换 PIT 上的冠军**。不是投资建议。

问题：冠军 B（`NONE|P12_HYST60|NONE|DONCH|CAP2|VT10|NONE`）一直在 PIT 上评价，仓库里原先没有它在 ext 上的数字。对照窗口、截断规则与 `runs/2026-11-21_ext_rerun/` 一致。

数据：总收益面板 v2（除权事件修正后的当前 `panel_tr2.pkl`）；只做多；延迟 1 日；t 收盘定仓，t+1 成交，t+2 生效。主口径 5bp，20bp 作敏感。

## 两种事先写清的口径

1. **CHAMP_EXT_FIXED**：固定 ext 52 只当池（不再做 P12）+ DONCH + CAP2 + VT10。把冠军的信号/上限/仓位直接套在原来的事后池上。评价起点与 ext_rerun 相同：EXT19 为 2019-08-13，EXT17 为 2017-08-14。
2. **CHAMP_EXT_P12**：P12_HYST60 在这 52 只内部运作，仍然 DONCH+CAP2+VT10。排名只用截断后可见的成交额，有效样本 150 根（与 DONCH 一致）。因名单在月末确定、下一交易日生效，实际起步比 FIXED 晚约半个月（EXT19 为 2019-09-02，EXT17 为 2017-09-01）。下文「同起点切片」把 FIXED / S4 / S2+VT15 也从这一天起重算，避免把这 10 余个交易日算进「P12 有没有作用」。

全市场 PIT 对照仍用标准 P12（250 根、不截断历史），为该起点重新起步，不是把 2014 年起的长跑书切开。

## 校准与冻结后改动

- **PIT 全历史 vs full_rebuild 缓存（float32）**：S4 日收益最大绝对差 1.823e-9，冠军 3.173e-9，均低于冻结的 1e-6，**通过**。起点 2014-06，lo=729，长度 4094，与缓存一致。
- **与 `ext_rerun/results.csv` 对齐**：冻结要求 CAGR/MDD/卡玛差 < 1e-10，**未通过**。原因不是脚本走错对照路径（仍调用 `ext_rerun.run_sat`），而是当前 `panel_tr2.pkl` 的修改时间晚于该结果表（结果表写于面板除权修正之前）。本 run 一律用修正后的当前 TR2，与 PIT 缓存同一套数据。偏差幅度：EXT 窗口卡玛最大绝对差约 0.0047（CAGR 约数个 bp）；PIT 同起点最大到约 0.047（PIT@2019-01-02 的 S4，20bp）。下文数字都是当前面板的重算，不以旧表为准。
- **冻结后改了脚本输出，判据与两种口径的定义未改**。补了 `start`/`lo` 列、评价起点之后的池统计（含淘汰次数）、以及同起点切片表。代码指纹 sha256 前 16 位：冻结时 `work/champion_ext.py` 为 `0f00c06c082a72c7`，补输出后为 `c35da037479eff17`。依赖未改：`ext_rerun` `8bae417fdf1eb786`，`c3x_combo` `1c679a918aa970f5`，`fw_engine` `628d1631f8bba8a0`，`pv_pools` `583a7c595f51cc6c`，`engine` `a3f50ea1d57afbcb`。

## P12 在 52 只里还有没有筛池作用？

结论：**没有持续的「猜挑 / 淘汰」作用。**「前 60」在最多 52 只的宇宙里几乎等于全集，一旦进入名单就不会被换出。

评价起点之后的月度统计（`pool_p12_summary.csv`）：

- EXT19：88 个月，平均 38.6 只（最少 27、最多 40），其中 67 个月满 40；同时点固定池平均约 47.7 只有行情。去掉名单诞生的首月后，月换手 0.44%，89.7% 的月份完全不变。**全程淘汰次数为 0，满 40 之后淘汰次数也是 0。**
- EXT17：112 个月，平均 35.8 只（最少 22、最多 40），同样 67 个月满 40；固定池平均约 43.3 只。去掉首月后月换手 0.52%，87.4% 的月份不变。**淘汰次数同样为 0。**

名单变化几乎只发生在截断后「满 150 根」的标的逐渐够格、把名单从 22–27 只补到 40 的阶段；补满之后就冻结。因此 P12 在这个小宇宙里实际做的是：用 60 日成交额做一次（加早期补位的）40 只上限，而不是每月再筛选。

同起点切片上，P12 相对冻结的 FIXED 仍有差距：EXT19 5bp 年化高 0.71 个百分点、卡玛高 0.038（11.73% / −16.13% / 0.727 vs 11.03% / −16.00% / 0.689）；EXT17 5bp 年化高 1.92、卡玛高 0.046。这应理解为「第一次按成交额留下的不超过 40 只」与「52 只全可用」的差异，加上早期规模更小，而不是滞后带在持续换血。该差距在 EXT19 的 20bp 上翻向：P12 卡玛 0.442，低于对齐后的 FIXED 0.480。**不能据此认为 P12 在 52 只里还有稳定的选池价值。**
