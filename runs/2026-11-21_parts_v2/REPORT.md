- 按冻结规则，**9 个零件的主臂没有一个两关都过**，所以正式的"只叠两关都过的零件"这一步，叠加集合是空的。

## 2. 方法（摘自 FREEZE.md）
- 回测从 2013-01-04 起，评估从 2014-01 起，前面一年当预热期。成本 5bp 和 20bp 两档。
- 两个基底：
  - **S4**：2014 起 10.7% / −24.9% / 0.428；
  - **C3 60% + S4 40%**：9.7% / −12.3% / 0.792。
  - 参考：C3 为 8.7% / −8.8% / 0.987；S4+CREDIT 为 12.2% / −16.9% / 0.722；C3 60% + (S4+CREDIT) 为 10.3% / −9.0% / 1.146。以上都是 5bp，见 `bases.csv`。
- **第一关（稳健性）**：
  - 2014-01 到 2023-11 每月一个起点，共 119 个，终点统一为 2026-11-13；
  - 通过条件：ΔCalmar 为正的起点占比 ≥ 70%，并且非重叠四段（2014-16 / 17-19 / 20-22 / 23-26）中至少 3 段为正。
- **第二关（同敞口对照）**，统计量统一用滚动起点 ΔCalmar 的中位数：
  - 择时类：乘数循环平移 200 次，要求 p ≤ 0.10；同时，对"同平均敞口的常数缩放"的中位差要 > 0；
  - 选股类：随机剔除同样个数的标的，100 个种子，要求 p ≤ 0.10；
  - 底仓时序动量：开关矩阵平移 200 次，再加一个常数对照。
- 分类以主臂、5bp 为准。

## 5. 注意事项
1. **全部是样本内结果。** 单零件共 36 个"臂×基底"，叠加探索 60 个，合计 96 次，登记在 `trials.csv`。之前的账本没有并进来。
2. **p 值在 0.04 到 0.13 之间的，对随机种子敏感。** 同一个 IVOL30 在组合上，单零件那次（种子 1000+）p = 0.069，叠加那次（种子 4242）p = 0.119。VOV80H 在 S4 上两次分别是 0.060 和 0.129。对照只抽了 100 到 200 次，"刚过 0.10"的结论不稳。
3. **四段里 2014-16 是择时类零件的共同弱点**：它们在 2015 年的反弹里减了仓。所以"正差占比高"大多来自 2017 年以后的起点，各起点之间又高度重叠。
4. **滚动起点的终点都是 2026-11-13**，起点越晚窗口越短，越受 2023 年以后的路径影响。
5. **美债、VIX 的数据是美国日期**，已经滞后 1 个 A 股交易日；国内数据也统一滞后 1 日，乘数再按 t+2 生效。北向资金的数据在 2024-08-16 之后中断，只作信息，不能实盘。
6. **隔夜跳空用的是不复权价**，绝对值超过 11% 的跳空当作除权剔除，可能还残留少量除权噪音。
7. **IVOL 和 S4 的 1/vol20 权重有重叠**，算是"低波"的又一种表达。它在不加社融时有用、加了社融就有害，说明两者抓的可能是同一段行情（2023 年以后的高波成长）。

## 6. 建议
- **不新增候选。** 这一轮没有主臂过两道关。
- 如果一定要留一个做影子观察，相对干净的是 US10Y30H（20 日美债上行超过 30bp 时卫星减半）。理由是：
  - 在 S4 和 C3 60% + S4 上，两次对照的 p 都 ≤ 0.06；
  - 叠在 S4+CREDIT 上，20bp 下仍有 73% 的起点为正。
  - 但它没过第一关（四段只有 2/4）。放进 C3 60% + (S4+CREDIT) 之后，Δ 中位数只有 +0.023，p 为 0.208（5bp）。所以只能记录，不参与决策。
- **IVOL30 不要叠在社融上。** 隔夜跳空、VIX、中债 2 年、底仓时序动量都进"别再跑"清单。
