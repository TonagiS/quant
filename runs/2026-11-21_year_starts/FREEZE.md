# year_starts 预登记（2026-11-21，跑结果之前冻结）

**问题**：从不同公历年的固定入场日重新空仓起步，看九条已有臂跑到同一截止日的结果是否稳，而不是把一条 2013/2014 年起的长跑路径切开。

全部为样本内研究，不是投资建议。本 run 是测量，不设「过关即换冠军 / 换实盘」判据，也不把某一个起点的第一名当作总结论。

数据：总收益面板 v2（`panel_tr2.pkl`）；PIT 池；只做多；延迟 1 日；t 收盘定仓，t+1 成交，t+2 生效。主口径 5bp，20bp 作敏感。截止日一律为面板末日 **2026-11-13**。

## 起点（11 个，名单与规则冻结，不得改）

- 2015 至 2024 每年上海市场第一个交易日
- 再加 **2014-06-03**（PIT 池首次满 40 只）
- 不加 2013（池未满），不随机抽日期

信号、池成员、社融等用该起点**之前**的历史预热（无前视）。组合从该起点**空仓**，按引擎惯例在起点收盘首次定仓、次日收盘成交、再次日生效，一直跑到截止日。禁止把一条更早起点的持仓路径切片当作「那一年入场」。

若某臂在该日尚不足 8 只有效标的，实际起步取其后第一个满足条件的交易日，并在结果里写明 `start`。

## 校准

用已知全历史数字做逐日复现（起点取与缓存相同的标准窗口 W2013，预热后约 2014-06 起）：

- PIT 上 S4、冠军：日收益与 `data/cache_full_rebuild` 对应缓存最大绝对差 < 1e-6（缓存为 float32）
- C3：日收益与 `data/cache_combo3/ref_5.npz`（及 20bp）的 `core` 最大绝对差 < 1e-6
- C3 60%+冠军：用上述缓存两腿按同一套 `mix` 得到的日收益，与本脚本现算结果最大绝对差 < 1e-6

若 2014-06-03 与标准缓存起点为同一日，则该起点上的 S4 / 冠军 / C3 应与缓存全历史书一致（不是切片，本身就是同一条空仓起步的书）。
