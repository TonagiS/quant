# 年度入场（11 个固定起点空仓起步，2026-11-21）

全部为**样本内**研究，不是投资建议。本 run 只测量「换一个公历入场日、从空仓重新建仓，跑到同一截止日」时九条已有臂看起来稳不稳。**不设过关换冠军 / 换实盘的判据，也不把某一个起点的第一名当作总结论。**

数据：总收益面板 v2；PIT 池；只做多；延迟 1 日；t 收盘定仓，t+1 成交，t+2 生效。主口径 5bp，20bp 作敏感。全部跑到面板截止日 **2026-11-13**。信号、池成员、社融等用起点之前的历史预热；每条路径都是该日起的新书，不是把更早起点的持仓切片。
