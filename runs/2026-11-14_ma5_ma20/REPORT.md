# MA5 上穿加仓 / MA20 下穿减仓 · 回测

日期 2026-11-14 · 脚本 `work/bt_ma5_ma20.py` · 产物 `runs/2026-11-14_ma5_ma20/`

## 结论

**这条规则的原样（满仓/清仓）没有明显优势，真正干活的是 20 日线，5 日线上穿只是噪声源。**

- 23 个标的横截面中位数：年化 **4.3%**，最大回撤 **-50.1%**，卡玛 0.095；买入持有是 3.8% / -56.6% / 0.083。超额中位数 **+0.1%/年**，跑赢比例 52% —— 等于抛硬币。
- 换手 **26 倍/年**（510300 七年 199 次交易），单边 5bp 成本一年吃掉 **1.4 个百分点**：毛收益 5.7% → 净 4.3% → 10bp 时只剩 3.1%。
- 病因清楚：MA5 上穿 **32 次/年**，其中 **46% 发生在 MA20 下方**（下跌中继的反抽），一买就套；等真跌破 MA20 才卖，又已经吐掉大半跌幅。所以回撤只从 -57% 降到 -50%，没质变。
- 加一道「只在 MA20 上方才认可上穿」的闸门（gate），中位数变成 6.1% / **-28.8%** / 卡玛 0.18；只守 MA20（hold20）是 6.4% / -35.2% / 0.17。**均线择时的收益来自长均线，不来自 MA5。**

## 规则与假设（必读）

- 信号用当日收盘价与均线比较，**次日收盘成交**，次日起计收益，无前视。
- 「加/减」按**单一资金池的仓位切换**处理（0~100%），不是追加新钱，所以收益口径是时间加权年化，不是定投 IRR。
- 成本：单边 5bp（与 `position/engine.py` 默认一致），另跑 0bp / 10bp 看敏感度。
- 起点：所有变体统一去掉 60 根预热 K 线。ETF 用 `data/cache2019`（2019-04 起），指数用 `data/cache2007`（2007 起，含 08/15/18 三轮熊市）。
- 口径变体：`full` = MA20 下穿清仓；`half` = 减到半仓；`ma60` = MA20 减半、MA60 清仓；`cross` = MA5/MA20 金叉死叉；`hold20`/`hold5` = 站上均线就持有；`bh` = 买入持有。

短均线拉到 8~10 只是把假信号减少一点，结构没变：**问题在「上穿短均线就满仓、跌破长均线才走」这个不对称结构**，参数救不了。
