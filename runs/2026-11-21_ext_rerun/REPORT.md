## 5. 要点
1. **舒适区确实舒适**：同样从 2019-08 起，S2+VT15 在 ext 上 Calmar 0.67（13.4% / −20.1%），在 PIT 上只有 0.33（7.6% / −22.9%）。S2 不加 VT 的差距更大（0.40 vs 0.15）。这部分差距主要来自事后选池。
2. **社融开关在 ext 上也有用，但方式不同**：
   - ext 上：S2+VT15 → +CREDIT，CAGR 从 13.4% 降到 11.7%，MDD 从 −20.1% 收窄到 −13.6%，Calmar 0.67 → 0.86。也就是用收益换回撤。
   - PIT 上（2019-08 起）：Calmar 0.33 → 0.59，收益和回撤同时改善。
3. **S4 的板块上限在 ext 上几乎没用**（0.70 vs S2+VT15 的 0.67），因为 52 只固定池本身已经比较分散。在 PIT 上它的作用明显得多。
4. **止损12% 在 ext 上中性**（0.86 → 0.87）。**人民币贬值闸门（CNY）在 ext 上是最好的单项卫星**：Calmar 1.00，2021-02→2024-02 段 +7.1% / −9.0%。3 月空仓+止损12% 为 0.96。
5. **底仓混合**（ext19，5bp）：
   - C3 50% + (S4+CREDIT+STOP12)：10.9% / −9.6% / 1.14，优于 C3 50% + S2+VT15 的 11.5% / −12.8% / 0.90。
   - C3 单独：9.0% / −8.8% / 1.03。
   - 20bp 下这三者几乎持平（Calmar 约 1.00 / 0.74 / 1.00）。
6. **ext 在 2017 起并不舒适**：2018 年和 2021–24 长熊伤得重，S2+VT15 为 11.5% / −28.1% / 0.41。CREDIT 把 MDD 降到 −17.6%，CNY 降到 −14.8%（Calmar 0.66）。在这个窗口，含底仓的组合 Calmar 都低于 C3 单独的 0.94。
7. **起点敏感**：PIT 池上 S4+CREDIT+OFF03+STOP12 从 2019-01 起 Calmar 0.60，从 2019-08 起 1.24。半年的起点差异就能让排名大幅变化，所以单一窗口的冠军不可信。
8. 结论：在 ext 和 PIT 两个池上都站得住的组合是 **C3 50–60% + (S4+CREDIT+STOP12)**（ext19 为 1.13–1.14，PIT W2019 为 1.01–1.19）。纯卫星里 S4+CREDIT+CNY 在两个池上都比较稳。ext 池的绝对收益水平不能当真。
