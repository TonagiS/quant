# framework_layers：市场状态 L0 / 两级趋势 L1 / 独立离场 L2，顺序闸门（样本内）

冻结：`FREEZE.md`（提交 dc160e0，在任何结果之前推送）。
底座：
- B1 = P12_HYST60|DONCH|CAP2|VT10（combo3 最佳）
- B2 = BASE|S2|CAP2|VT15（= S4）

数据：总收益面板 v2；统计从 2014‑06 起。判据：对参照，114 个滚动起点中卡玛改善 ≥ 70%、中位差 > +0.05、4 段中 ≥ 3 段更好，5bp 和 20bp 都要满足。**全部为样本内结果，不是投资建议。**

## 1. 结论
1. **三层在两个底座上，19 个变体全部没有通过**（38 次检验，0 个通过）。按顺序闸门，什么都不叠加：两个最终框架都等于各自的底座。所以叠加结果就是「无变化」。
2. **B1（combo3 最佳）上，没有任何一层有帮助。**
   - L0 市场状态：9 个变体的中位差全部 ≤ 0。最好的是 RG_TREND|BEAR30，5bp 为 49.1% / −0.005 / 2 段。
   - L1 两级趋势：4 个变体都明显更差，中位差 −0.485 到 −0.918。周线 30 周过滤把平均敞口压到 0.32，切掉了大量收益。
   - L2 离场：最好的是 TIME30（66.7% / 0.000 / 2 段，几乎不触发）和 HYST10（全期卡玛 0.909 > 0.879，但滚动中位差 −0.175）。跟踪止损 TS8/12/15、唐奇安下轨 DCL20 都更差。
3. **B2（S4）上，L0 的 RG_TREND 三个映射在滚动起点上很强，但分段只赢 2/4，判据不过。**
   - RG_TREND|SWITCH：5bp 100% / +0.428 / 2 段；20bp 100% / +0.200 / 2 段。全期卡玛 0.595（S4 0.433），MDD −19.0%（S4 −25.0%）。
   - 它赢在 2020‑22（0.697 vs 0.348）和 2023‑26（0.902 vs 0.340），输在 2014‑16（0.954 vs 1.269）和 2017‑19（0.609 vs 0.613）。
   - 由于所有滚动窗口都延伸到 2026，后期的大幅改善让「起点占比」达到 100%。分段判据正好抓到了：这种改善只集中在后半段。
   - L1 的 W30_BO（周线过滤 + 新买入须接近突破）：5bp 85.1% / +0.119 / 2 段，20bp 88.6% / +0.173 / 2 段，同样只赢后两段。
   - L2 离场在 S4 上全部不过，中位差 −0.083 到 −0.013。
4. **两个底座的结论不一致**，说明这些层**不具有普适性**。在 S4 上看到的「状态择时改善」，一换到已经更好的 B1 上就消失了：B1 的 RG_TREND|SWITCH 是 2.6% / −0.197 / 1 段。
5. **最终框架对比**（因为等于底座，就是底座本身的数字）：
   - B1：5bp 卡玛 0.879 / MDD −13.9%，对 S4 100% / +0.581 / 4 段，对宽基 VT15 100% / +0.730 / 4 段；20bp 卡玛 0.603。
   - 作卫星配 C3 60%：5bp 卡玛 1.259（C3+S4 0.779，C3+宽基 0.792）。
6. **过拟合校正**（40 条序列 = 38 个变体 + 2 个底座，5bp）：
   - PBO‑CSCV = 0.195。
   - B1 的 DSR = 0.987（N = 40）；把 combo3 的 384 次也算进去（N = 424）时为 0.935。
   - S4 的 DSR 是 0.837（N = 40），算入 combo3 后为 0.601。
7. **随机零假设**：最终框架没有新增的层，所以不需要做。B1 底座的随机排序零假设在 combo3 里已经做过：滚动中位卡玛和全期卡玛都在 100% 分位。

**判定**：L0、L1、L2 都不纳入。B1 仍然是 combo3 定下的候选（并行影子运行），S4 不变。

## 6. 过拟合校正（`overfit.json`）
- 试验集：两个底座 × 19 个变体 + 2 个底座 = 40 条日收益序列（5bp，2014‑06 起）。
- PBO‑CSCV（S = 16）= 0.195，logit λ 中位数 1.00。
- DSR：
  - B1 底座：年化夏普 1.085，零假设下预期最大夏普 0.429，DSR 0.987；算入 combo3 的 384 次（N = 424，预期最大夏普 0.640）时为 0.935。
  - S4：DSR 0.837；N = 424 时为 0.601。
- 因为没有层通过，PBO/DSR 主要说明 B1 在这批变体里仍是最好的，并且在扩大的试验数下 DSR 仍高于 0.9。

## 7. 冻结后追加（非闸门）：层的效果是否依赖选股（`explore_null_long.csv`）
对 4 个改善最大但没通过的层，在 100 个随机排序底座上各加一次（同一种子的随机底座作参照），看中位卡玛差：
| 层 | 随机底座上的中位差（中位数） | 中位差 > 0 的种子占比 |
|---|---|---|
| S4 + RG_TREND\|SWITCH | +0.095 | 97% |
| S4 + RG_TREND\|BEARCASH | +0.105 | 99% |
| S4 + W30_BO | +0.146 | 95% |
| B1 + RG_TREND\|BEAR30 | −0.000 | 49% |

解读：在 BASE 池 + S2 候选结构上，大盘趋势择时和周线过滤对「随机选股」也有改善，说明效果来自择时而不是选股。但这类择时在 2014‑19 输、2020‑26 赢，判据把它拦下了。在 P12 + DONCH 结构上，这种改善完全不存在。

## 8. 注意事项
- 全部是样本内结果。19 个变体的参数（MA200、30 周、8/12/15%、20 日、30 日、阈值 0.6/0.35 等）是事先拍定的，没有扫参；扫参的话总能找到「通过」的格子。
- 大盘只用沪深300 ETF（510300）的总收益价格作代理，没有用中证 800 或指数本身。
- 冻结前跑过一次冒烟检查，B2 上各变体的全期卡玛当时已经打印出来（定义没改）。冻结前还修了 combine 中换袖子成本的一个索引错误。
- 冻结后的改动：
  - null 模式在「没有可做零假设的层」时写出空文件，导致 post 报错，改为不写文件；判据未改。
  - 新增 explore 模式（第 7 节），属于事后、非闸门分析。
- SWITCH 换袖子按全卖全买计成本，偏保守；L2 离场后的资金持现金到下次调仓（0 收益）。
- 滚动起点的窗口都延伸到 2026，后期表现会主导「起点占比」；这次分段判据起了决定作用。
