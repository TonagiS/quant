冠军 B = P12_HYST60|DONCH|CAP2|VT10（即本 run 的最简三层主口径 MIN3_P12）。S4 = BASE|S2|CAP2|VT15。**冠军是全样本挑出来的，对它的比较对冠军有利。**

**结论**：等权混合没有在两个切分方向都比成员平均更稳，也不能换冠军，不列为并行观察。

### A3 成本感知再平衡
底座为 MIN3_P12 与 S4。相对日历 10 日（现行约定）：

- **DEAD2 / DEAD4**（单券权重变化小于 2 或 4 倍往返成本则不交易）：几乎没起作用。MIN3 上 20bp 换手 19.67→19.63 / 19.55，成本拖累 3.933%→3.926% / 3.910%，跟踪误差 0.11% / 0.26%，卡玛 0.603→0.602 / 0.613。死区远小于 10 日再平衡的典型权重变化。
- **DAILY**（每日调到目标，VT 仍 10 日）：换手约 101，20bp 成本拖累约 20.2%，卡玛落到 −0.113（MIN3）和 −0.083（S4），两段都差。
- **SETONLY**（只在进出只时调，纯权重漂移不调）：几乎不省成本，跟踪误差约 5%，MIN3 的 2020-26 卡玛从 0.618 掉到 0.096（20bp）。S4 上全期卡玛略升（20bp 0.229→0.290），但 2014-19 从 0.502 掉到 0.319，两段翻转。
- **TURNCAP40**（单日双边换手上限 0.40）：换手砍到约 9.4，20bp 成本拖累 3.93%→1.89%（省 2.05 个百分点），但跟踪误差 4.64%，卡玛 0.603→0.359，MDD −14.7%→−23.7%。省下的成本没有换来更好的风险调整收益。

类平均相对日历再平衡，两段卡玛增量同号为负。20bp 下更关键的结论是：不要改成每日再平衡；死区在现行 10 日频率上可忽略；换手上限会省成本，但跟踪误差和回撤更差。保持日历 10 日。

## 3. 各层单要素赛道（按该要素在做什么来评）

### 选池：是否挑出更好的宇宙？
池内成员等权、延迟后的 20 / 60 日后向收益（不是组合卡玛）：

- BASE：P1 月均 fwd20 / fwd60 为 +1.29% / +3.63%，P2 为 +0.28% / +1.06%；月换手 10.1% / 11.3%。
- P12：fwd20 / fwd60 两段都略高于 BASE（P1 +1.43% / +3.87%，P2 +0.36% / +1.25%），换手低得多（1.99% / 4.08%）。这是滞后带的本意。
- 四个新池的平均 fwd20、fwd60 对 BASE 两段翻转（P1 略正、P2 为负）；对 P12 则两段都更差。TOG20 / SHR4 月换手高达 53–61%，SECROT 约 39%，宇宙本身更吵。
- 「新进入成员 20 日后向对 P12」两段为正，主要是因为 P12 在 2020-26 的新进入成员后向是 −2.86%（样本少、且是被补进池的名字），不是新池宇宙更好。不作「有用」解读。
- 组合卡玛上，新池平均明显低于 MIN3_P12；SECROT 在主口径上 5bp / 20bp 对 S4 全期通过，但 2014-19 的 OOS 滚动增量不过关（结构通过不成立）。

份额变化（SHR4）可做：评价窗内每月约 16–30 只有沪市份额（总体均值 24.9），深市按中性分处理，没有因数据不足而放弃。海外/商品子池（XBCM）也可做：2014 年跨境平均约 3 只、商品约 1.6 只（个别月商品为 0，名额归国内），2017 年起基本满 8+4。

### 信号：入场是否更好？
新买入后 20 / 60 日收益与胜率（成交日收盘起算），对照 DONCH、S2，以及同池随机 5 只（20 种子）：

- DONCH（主口径）：P1 的 20 日均 +1.63%、胜率 57.7%，60 日 +4.58% / 65.2%；P2 为 +1.28% / 56.1% 与 +2.25% / 52.1%。60 日两段都明显高于随机（随机 P1 +3.85% / 61.9%，P2 +1.16% / 47.5%）。随机打分书 5bp 全期卡玛 10/50/90 分位为 0.252 / 0.349 / 0.458，DONCH 的 0.879 远在 90 分位之上。
- S2：P2 的 20 日均只有 +0.42%，弱于 DONCH 和随机。
- 新信号类平均：20 日均收益、20 日胜率对 DONCH 两段翻转；60 日均收益两段都更差。
- 单个上看，回踩突破的 20 日均收益两段都高于 DONCH（P1 +2.93%、P2 +1.58%），但 60 日在 2020-26 为 −1.02%，组合敞口只有 0.35，卡玛差。布林收窄一年只有几十次入场，组合几乎空仓。量能突破的组合对 S4 在两档成本、两个 OOS 方向都通过结构判据（5bp 卡玛 0.784、滚动 0.923），但入场后向并不比 DONCH 更好，对冠军未过（20bp 卡玛 0.492 vs 0.603）。按冻结的「不按单个排名取舍、须对冠军通过才换」处理，只作记录，不列为观察对象。

## 4. 是否通过冻结判据；最终建议

- **换不换冠军：不换。** 没有任何结构变体或预先堆叠对冠军在 5bp 与 20bp、两个切分方向上都通过。
- **最简三层**：主口径就是冠军，对 S4 和宽基 VT15 仍然两边都站得住；BASE 池上的同样三层也对 S4 通过，但明显弱于 P12。结构本身成立，池还是用 P12。
- **多模型等权、成本感知**：都不通过，也不列为并行观察。再平衡维持日历 10 日。
- **新要素 / 堆叠**：类平均在主指标上没有「两段同号为正」。量能突破对 S4 通过但入场质量和对冠军都不支持把它升为观察对象。
- 过拟合按用户意见可以不考虑，但以上全部仍是样本内（切分为伪 OOS）。
