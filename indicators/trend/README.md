# indicators/trend —— 涨势/跌势指标分开研究

2026-11-04 建。目标：把“入场准入（涨势）”和“退出/降仓（跌势）”拆成两条独立的指标线，
分别预登记、分别给证据等级，再组合（涨势 AND、跌势 OR）。

## 为什么单独开
- `indicators/` 里 45 条规则与 S2 证据都已固定；这里只做**新增指标**，不动既有结论、不改 shadow v1。
- 跌势侧目前只有 `cash_gate_120`（B）；其余卖出类（回撤节流、净值均线、固定止损、跌破MA60止损）全是 D，
  是明确的空白，优先补。

## 目录
```
indicators/trend/
  README.md              本文件
  config.json            数据路径、基线参数、证据口径、组合纪律
  prereg/
    registry_trend.csv   本子项目的预登记簿（先写行、记 code_sha256、再跑）
  code/                  新增指标的脚本（每个假设一个文件，只读复用 indicators/code 的函数）
  results/               每次运行产物：日期_编号_名称/
```

## 硬纪律（与主项目一致，违反就不算数）
1. 先登记后跑：`prereg/registry_trend.csv` 写清假设、宇宙、冻结参数、判据，并记脚本与被复用文件的 SHA256；跑完只填结果/判定。
2. 每轮最多 3 个新指标，分侧（up/down）登记，不许看了结果再换参数重跑。
3. 判据不通过就写未通过；通过只算“参数稳健”，不是样本外。
4. 不改 `indicators/code/` 下既有脚本、不改 `position/live/shadow/RULES_v1.md`、不碰系统权限。
5. 成本必须算：换手增量 × 单位成本 < 卡玛增益，否则不采纳（S2 的盈亏平衡只有 25/29bp）。

## 证据口径（沿用 indicators/README.md）
- 规则层：三段同向 + `NW_t≥2` + 不重叠 t≥1.5 过初筛；45 条口径下 Bonferroni 需 t≥3。
- 组合层：加到 S2 上，看卡玛、最大回撤、年化换手的变化，并与同平均仓位的固定缩放对照。
- 稳健：OFAT（窗口/阈值/确认天数）、剔除涨幅前 3、分年。

## 组合约定（待第一轮检验后再定稿）
- 涨势：慢信号（60~120 日），多条件 **AND**，宁缺毋滥。
- 跌势：快信号（5~20 日），多条件 **OR**，宁可误杀。
- 防抖：±1% 迟滞带或 5 日确认；具体数值在预登记里冻结。
