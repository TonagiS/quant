# MACD 钝化 / 结构（公开描述还原，非原指标源码）

实现：`macd_structure.py`（`calc_macd` / `_bottom_state` / `analyze` / `structure_series`）。
本页只解释口径与证据，代码以文件为准。

## 1. 定义（底部；顶部把价格和 DIF 取负后套用同一套）

- **前低**：最近 `lookback=120` 根内、排除最近 `recent=5` 根之外的最低收盘价。
- **前低 DIF**：前低附近 ±`trough=5` 根内 DIF 的最小值。
- **钝化**：最近 `recent` 根内出现 `收盘价 < 前低`，但 `DIF > 前低DIF`（价格新低、动能不新低）。
- **结构形成**：钝化之后 DIF 首次拐头向上（`DIF[j] > DIF[j-1]` 且 `DIF[j-1] <= DIF[j-2]`）。
- **钝化消失**：最近一次创新低那天 DIF 也 ≤ 前低 DIF（动能同步新低），钝化失效。

参数：`DEFAULTS = dict(lookback=120, recent=5, trough=5)`；MACD `12/26/9`。
`structure_series` 逐日滚动，第 t 天只用 t 及以前数据；盘中追加临时 K 线得到的是"预判"，收盘可能变。

## 3. 使用约束

- 不得单独作为买卖信号；不得进入 shadow v1（v1 已冻结，不含结构）。
- 若未来要测，先写预登记：明确"结构事件后 N 日超额"的基准（同池截面均值）、Newey-West t、三段同向、随机位移对照。
- 结构信号在 14:30 用临时 K 线会变，实盘只能当"盘中提示"，不能当收盘确认。

## 4. 已知坑

1. 前低贴着窗口左边界时不可靠（`i0-start < trough` 直接返回"无"）。
2. 上市不足 ~150 根时 `structure_series` 前 120 根为"数据不足"，不要当"无信号"统计。
3. 结构状态是路径依赖的，循环位移对照会破坏持续性，这是有意的（检验"结构形态"本身而不是"位置"）。
