# 计划：单支策略网格 + 组合两项 + 省 token harness（待确认，2026-11-14）

**数据现实**：cache2019 / cache2007 全部只有 `date, close, amount` 三列。没有 OHLC、没有成交量。
→ MA / 动量 / 波动 / 回撤 / 通道 / 周月线 / 成交额比 都能做；**ATR、K 线形态、真实成交量、缺口类全部做不了**，除非另拉 OHLC（90 标的 × 17 年，约 10 分钟）。

---

## H1. 单支 harness（省 token 的基础设施）

`work/single_asset_harness.py`（约 180 行）：
- 一次加载 90 标的（53 ETF + 15 指数 + 22 蓝筹），预计算因子矩阵：MA20/30/60/120/200、mom20/60/120、vol20/60、dd（滚动高点回撤）、amount 比、周/月线重采样、唐奇安 20/55 高低、布林(20,2)。
- 规则用**声明式表**：`RULES = {"跌破MA30半仓": F(ma=30, half=True), ...}`，底层统一算 `pos(t)`（含 delay=1、滞回、可选 2% 缓冲）。
- 一次跑完输出长表 CSV：`group, name, window, rule, cagr, mdd, calmar, sharpe, avg_pos, turnover`。
- 自带汇总：每规则相对满仓的卡玛增量（中位、正例率、分年段）。
- 以后加一个新假设 = 往 RULES 加一行 + 跑 2 秒。**这是省钱的关键，先做它。**

## S. 单支网格（约 40 个候选，一次跑完）

| 族 | 候选 |
|---|---|
| A 趋势/均线 | MA20/30/60/120/200 × 半仓/清仓（10） |
| B 动量 | 20/60/120 日动量 < 0 → 半仓、清仓（3） |
| C 波动 | VT8/10/12/15/20；vol60 分位 > 80% → 半仓（3） |
| D 回撤 | 滚动高点回撤 10/15/20/25% → 半仓（4） |
| E 量能 | 额比(5/60) < 0.7 → 半仓；额新高+价新高（2） |
| F 周/月线 | 周 20MA 上下；周 20MA 转下；月 MA6 上下（3） |
| G 通道 | 布林中轨下方半仓、唐奇安 20/55 日下轨清仓（3） |
| H 两两串联 | 仅取 A×C、A×D、B×D、C×D、F×A 各 1 组，形式固定为 min()（10~14） |

**选优规则（先定死，不许事后改）**：中位卡玛增量 ≥ +0.03、正例率 ≥ 60%、ETF/指数/蓝筹 至少两组同向、2012 段同向。过关的进下一轮，最多 3 个。

**记账**：这一轮是**探索**（和 `single_asset_rules.py` 同口径，不进 registry）；最终入选的 1~3 个才写正式预登记（+1~3 次试验数）。

## P. 组合层（2 项）

- **P1 VT15 敞口按持仓质量加权**：敞口 × (站上 MA60 的持仓数 / k)。1 个假设，走 engine，15 分钟。
- **P2 单支层叠 S2+VT15**：已跑完（基线 0.984 → 叠加后 0.846/0.814/0.924），**只需写 REPORT 归档，不重跑**。
- **P3（可选）集中持仓场景**：k=2、cap 40% 的 S2 上再叠单支层——这是"单支结论"真正该用的地方，2 个假设，20 分钟。
